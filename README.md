# Calculadora de Circuitos RLC

Calculadora desenvolvida em **Python** para realizar cálculos relacionados a circuitos **RLC**, aplicando conceitos de eletrônica e programação.

O projeto foi desenvolvido como forma de integrar conhecimentos adquiridos durante minha formação em **Engenharia Eletrônica** com meus estudos atuais de **programação e Ciência da Computação**.

## Objetivo

O objetivo do projeto é facilitar cálculos de circuitos RLC por meio de uma aplicação simples, permitindo inserir os parâmetros do circuito e obter os resultados de forma automatizada.

## Funcionalidades

O programa permite realizar cálculos relacionados a:

* Circuitos resistivos em corrente contínua (CC)
* Circuitos RL em corrente contínua (CC)
* Circuitos RC em corrente contínua (CC)
* Circuitos RLC em série em corrente alternada (CA)
* Circuitos RLC em paralelo em corrente alternada (CA)
* Frequência de ressonância

## Tecnologias utilizadas

* **Python 3**
* Operações matemáticas
* Estruturas condicionais
* Funções
* Entrada e processamento de dados

## Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/Marcaoo/CalculadoraCircuitosRLC.git
```

### 2. Acesse a pasta

```bash
cd CalculadoraCircuitosRLC
```

### 3. Execute o programa

```bash
python calculadora.py
```

> O nome do arquivo pode variar de acordo com a estrutura atual do projeto.

## Exemplo de utilização

Ao executar o programa, o usuário pode selecionar o tipo de circuito que deseja analisar e informar os valores necessários para o cálculo.

A aplicação processa os dados fornecidos e apresenta os resultados correspondentes no terminal.
